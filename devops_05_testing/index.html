    Introducción a testing¶

    1. Pruebas para una API¶

    Si desea probar una API puede usar el módulo httpx.

    Ejemplo: Probar una API

    import httpx

BASE_URL = "http://localhost:8000"

def test_get_users():
    response = httpx.get(f"{BASE_URL}/users/")
    assert response.status_code == 200
    assert isinstance(response.json(), list)

def test_create_user():
    response = httpx.post(
        f"{BASE_URL}/users/",
        json={"name": "John Doe", "email": "johndoe@example.com", "phone": "123456789"}
    )
    assert response.status_code == 200
    data = response.json()
    assert data["name"] == "John Doe"

    2. Integración con GitHub Actions¶

    Puede hacer que las pruebas se ejecuten automáticamente en cada push con GitHub Actions.

    Cree un archivo en .github/workflows/test.yml:

    name: Test API

on: [push]

jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout del código
        uses: actions/checkout@v4

      - name: Instalar dependencias
        run: |
          python -m pip install --upgrade pip
          pip install pytest httpx

      - name: Ejecutar pruebas
        run: pytest tests/

    3. pytest¶

    pytest es un framework de testing para Python que permite escribir pruebas de manera sencilla y estructurada. Es más flexible y poderoso que unittest, ya que:

    • Permite escribir pruebas con menos código.
    • Usa assert en lugar de métodos como self.assertEqual().
    • Soporta fixtures para preparar datos antes de ejecutar las pruebas.
    • Puede ejecutar solo pruebas específicas con pytest -k nombre_prueba.

    3.1. Instalación de pytest¶

    pip install pytest

    Para verificar la instalación:

    pytest --version

    3.2. Comparación entre unittest y pytest¶

    Para comprender pytest observe la misma prueba escrita en unittest y pytest_

    Ejemplo con unittest 

    import unittest

def suma(a, b):
    return a + b

class TestSuma(unittest.TestCase):
    def test_suma(self):
        self.assertEqual(suma(2, 3), 5)
        self.assertEqual(suma(-1, 1), 0)
        self.assertNotEqual(suma(3, 3), 7)

    Ejemplo con pytest (equivalente, pero más simple) 

    def suma(a, b):
    return a + b

def test_suma():
    assert suma(2, 3) == 5
    assert suma(-1, 1) == 0
    assert suma(3, 3) != 7

    Diferencias clave: - No necesitas crear una clase TestSuma. - assert reemplaza self.assertEqual() y self.assertNotEqual().

    3.3. Escribiendo Pruebas con pytest¶

    Un archivo de prueba en pytest debe: 1. Empezar con test_ o contener funciones que empiecen con test_. 2. Usar assert para verificar los resultados esperados.

    Ejemplo de pruebas básicas

    Definición de las pruebas 

    # File: test_script.py

# Función a probar
def es_par(n):
    return n % 2 == 0

# Pruebas
def test_es_par():
    assert es_par(4) == True
    assert es_par(7) == False

    Para ejecutar las pruebas basta indicar el nombre del fichero:

    pytest test_script.py

    Si test_script.py contiene pruebas, pytest las ejecutará automáticamente.

    Lo habitual es que el fichero de pruebas sea independiente al código. En ese caso las funciones a probar estará en un fichero y los test en otro:

    El módulo con las funciones

    # File: funciones.py

def es_par(n):
    return n % 2 == 0

...
    Y el fichero con las pruebas

    # File: test_funciones.py
from funciones import es_par

# Pruebas
def test_es_par():
    assert es_par(4) == True
    assert es_par(7) == False

    3.4. Uso de Fixtures en pytest¶

    Los fixtures permiten preparar datos antes de ejecutar las pruebas.

    Ejemplo con Fixture 

    import pytest

@pytest.fixture
def datos_usuario():
    return {"nombre": "Juan", "edad": 30}

def test_usuario(datos_usuario):
    assert datos_usuario["nombre"] == "Juan"
    assert datos_usuario["edad"] > 18

    ¿Qué hace el fixture?

    • @pytest.fixture define datos_usuario(), que retorna un diccionario con datos de prueba.
    • test_usuario() recibe datos_usuario automáticamente.

    3.5. Ejecutando Pruebas¶

    Puedes ejecutar pruebas de diferentes maneras:

    Ejecutar todas las pruebas 

    pytest

    Ejecutar pruebas en un archivo específico 

    pytest test_script.py

    Ejecutar solo una prueba específica 

    pytest -k "test_es_par"

    Mostrar salida detallada 

    pytest -v

    Detenerse en el primer fallo 

    pytest -x
